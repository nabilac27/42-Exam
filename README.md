# 42 Exam

Personal solutions to the **C/C++ programming challenges** from the **42 Exams**.

- **Rank 03** uses the *old* exam subjects (`printf`, `get_next_line`).
- **Rank 04** uses the *new* subjects (Oct 2025).

## About

The 42 core curriculum is organized into **ranks** (also called circles or levels) from **00 to 06**. From **rank 02 to 06**, students must pass **timed exams** covering the C and C++ concepts taught up to that point.

- **Duration:** 3 hours
- **Restrictions:** no internet or external resources
- **Difficulty:** each rank adds more complex logic, edge cases and lower-level knowledge
